## 0.1.0

First version of the CLI, a separate Go module tagged `cmd/docuconf/vX.Y.Z`.

### Features

* `docuconf export`: exports a Go config struct as `contract.cue`.
* `docuconf vet` and `docuconf render`: check platform values, files and policy against a contract, and render
  them.
* `docuconf helm`: values schema and contract files for a Helm chart, with the library chart.
* `docuconf exec` and `docuconf check`, and the conformance runner used by every SDK.
