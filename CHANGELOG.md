## 0.1.0

First version of the Go SDK and the docuconf specification `v1alpha1`. The CLI in `cmd/docuconf` is a separate
module with its own changelog, [cmd/docuconf/CHANGELOG.md](cmd/docuconf/CHANGELOG.md).

### Features

* The contract specification (`spec/SPEC.md`) with its CUE meta-schema, the shared conformance suite and the
  edge-case catalogue.
* Declarations on [caarlos0/env](https://github.com/caarlos0/env) structs: descriptions from doc comments, secrets,
  ranges, lengths, patterns, enums, URL schemes, durations, list bounds and file inputs.
* Boot validation of variables and file inputs (TLS key pairs, CA bundles, keystores, config files) that reports
  every problem at once with stable error codes, and reload watching.
* Contract export (`Export`, `ContractCUE`), contract-first mode, config-file overlays and injected values.
* The `orders` example, the Helm example charts and the Go-struct-to-Deployment walkthrough.
